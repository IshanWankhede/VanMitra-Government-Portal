# Design system
Full token reference, components, layout and QA checklist: `design.md` (derived from `VanMitra-AI_Theme_UI_Style_Guide.docx`).

Summary: forest green (#1A4331, #2D765C) and warm orange (#FF8D20); orange only for the primary action, dark-mode active nav, focus ring and progress; status colours only for status (soft pill with icon and text); Inter + Noto Sans Devanagari; 8-pt spacing; 16px card radius; full Light/Dark themes; one icon set (lucide). Sidebar is a floating rounded green panel with a sliding active indicator; top bar is light with a border. English is the primary UI language with a whole-UI EN/मराठी switch (no inline bilingual strings).
The prototype (`prototype/`) is the working visual reference; the AI Studio prompts that produced it are in `ai-studio-prompts/`.
